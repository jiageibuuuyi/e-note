# Security Policy (安全响应规范)

## Supported Versions
Currently, security updates and vulnerability patches are committed to the latest release branch:

| Version | Supported |
| :--- | :--- |
| **v1.0.x** | :white_check_mark: Supported |
| < v1.0 | :x: Not supported |

## Reporting a Vulnerability
We take the security and local-first privacy of **e-note** seriously:

- If you discover a potential security vulnerability or local database exposure risk, please **do NOT** open a public issue.
- Instead, please draft a confidential security advisory or contact the maintainers via GitHub Private Vulnerability Reporting or via email.
- Please provide a detailed description of the vulnerability, steps to reproduce, and potential impact.
- We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure timeline.
