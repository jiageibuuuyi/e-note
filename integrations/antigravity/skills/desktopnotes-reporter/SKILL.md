# 电子便签 (DesktopNotes) 智能周报月报助手

本 Skill 为用户本地运行的 **电子便签 (DesktopNotes)** 提供智能数据提取、任务分析与专业汇报生成能力。当用户希望生成周报、月报、年报、季度总结或梳理待办进展时自动触发。

## 🎯 核心能力与场景

1. **自动提取真实便签与任务**：从 `%LOCALAPPDATA%\DesktopNotes\data\app.db`（或 MCP 工具）安全读取已结项完成的任务、进行中待办与随手备忘。
2. **多层级任务树智能还原**：支持识别父子任务关系（如大项目下的各项子任务拆解），按业务模块或主线项目聚合。
3. **多类型汇报生成**：
   - **工作周报 (Weekly)**：聚焦本周关键交付、攻坚修复、进行中任务、下周规划与风险阻碍。
   - **工作月报 (Monthly)**：聚焦月度核心里程碑、业务价值、模块交付度量与次月目标。
   - **年度总结 (Yearly)**：全年大事件与关键攻坚全景复盘、交付数据洞察与新一年战略演进。
4. **多风格模版切换**：
   - `standard`（职场通用交付版）
   - `engineering`（研发技术向，含代码/架构/Bug/技术债）
   - `okr`（目标对齐、KR达成与信心指数复盘）
   - `executive`（管理层高层极简看板）
5. **双向写回**：可将生成的最终汇报作为便签、或将下阶段规划作为新任务安全写回电子便签中。

## 🛠️ 执行流程与规范

### 第一步：明确统计周期与汇报风格
- 用户若未明确指定周期，默认匹配当前自然周期：
  - “写周报” / “生成本周总结” -> `this_week` (本周一至周日)
  - “生成上周周报” -> `last_week`
  - “写月报” -> `this_month`
  - “年报 / 年度总结” -> `this_year`
- 若用户有特定身份倾向（如研发组长、产品经理、独立开发者），自动选用最匹配的模版风格。

### 第二步：调用工具提取数据
- **推荐工具**：
  - 若已配置 MCP 工具：
    - 调用 `desktopnotes_get_report_data` 获取结构化交付上下文。
    - 或调用 `desktopnotes_generate_report` 获取基础排版。
  - 若通过命令行或脚本：
    - 执行 `python integrations/mcp/desktopnotes_mcp.py --report [weekly|monthly|yearly] --template [standard|engineering|okr|executive]`

### 第三步：深度润色与价值升华 (LLM Post-Processing)
AI 不应仅仅机械罗列待办清单，而应当：
1. **提炼业务价值**：将孤立的标题（例如“样式美化换皮”、“支持多级子任务”）升华聚类为有商业与技术价值的成果条目（例如“【交互体验升级】重构拟真便签视觉系统，优化纸张折痕与图钉层级”、“【核心引擎能力】实现多级树形子任务排布与状态级联联动”）。
2. **数据量化表达**：突出交付数量、P0/P1 高优先级攻坚完成率与零逾期表现。
3. **风险预警**：对截止日期临近或已过期的进行中任务进行醒目预警，并给出后续应对策略。

### 第四步：输出与反向沉淀
- 输出优雅规范的 GitHub 风格 Markdown 报告。
- 主动询问用户：
  > “是否需要将该汇报直接保存回桌面便签作为备忘归档，或将下阶段计划自动录入为便签新任务？”
- 若用户确认，调用 `desktopnotes_create_record` 完成自动化写回。
